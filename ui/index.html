What can you do here?

Create

Make images from words. Choose FLUX or Qwen, size, seed, speed and quality. Save or vary the result.

Edit

Upload or paste a photo. Add, remove, restyle, change faces or extend the frame; compare before and after.

Assist

Ask a local model to reason, write or code. Turn on web, memory, project reading, workers, computer control or WhatsApp as needed.

Local by default. Frontier by choice.

Assist starts local. Smart routing suggests a frontier model for complex text requests when an API key is configured, and asks permission each time. Frontier mode lets you choose Luna, Sol or Astra. Cloud chat sends only your current text by default. You can opt in to include recent chat; no local files, screenshots, saved memory or WhatsApp messages are automatically attached. Token fields cap each request; the session budget limits use in this running app, not your provider bill.

More ways to work

  • Terminal commands, an OpenAI-compatible image API and MCP tools for other assistants.
  • Import and quantize image models, add LoRAs, and reproduce past images from saved settings.
  • Computer actions and outgoing WhatsApp messages require individual approval. Mac permissions and WhatsApp pairing are separate setup steps.
